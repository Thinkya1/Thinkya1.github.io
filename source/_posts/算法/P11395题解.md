# P11395

## 题目

题目描述：

喵喵喵群里面，吃喵喵是坏文明。

现在群友有  个问题，每个问题形如 `A or B?`，其中  为仅含小写字母的非空字符串。

对于每个问题，你可以回答  或  中的任意一个不是 `eat` 的字符串。特别地，如果  和  都是 `eat`，你需要回答 `or`。

输入格式：

输入的第一行有一个正整数 ，表示问题的数量。

之后有  行，每行有一个问题。

输出格式：

对于每个问题，输出一行一个字符串，表示你对于这个问题的答案。

数据范围与说明：

【样例 1 解释】

- 对于第一个问题，你可以从 `yummy` 和 `yucky` 两个单词中的任意一个，所以既可以回答 `yummy` 也可以回答 `yucky`。**注意：在这个问题输出 `or` 将导致答案错误。**
- 对于第二个问题，因为第一个单词是 `eat`，要避开，因此**必须**输出 `stick`。
- 对于第三个问题，因为第二个单词是 `eat`，要避开，因此**必须**输出 `rua`。
- 对于第四个问题，两个单词都是 `eat`，所以要输出 `or`。

【样例 2 解释】

本样例共有  种本质不同的输出（除了第  个问题的两个字符串一样外，其他问题都有两种可能答案），这里仅展示其中一种可能的输出。

【数据范围】

对于全部数据，保证 ，每个问题中的字符串  均不超过  个字符，且仅含有小写字符。

本题共有  个测试点，不同测试点的分值和特殊性质见下表：

| 测试点编号 | 特殊性质 | 分值 |
| --- | --- | --- |
| 1 | 都不是 `eat` |  |
| 2 | 一定是 `eat`， 一定不是 `eat` |  |
| 3 | 一定是 `eat` |  |
| 4 | 一定是 `eat` |  |
| 5 | 一定有一个不是 `eat` |  |
| 6 | 无特殊性质 |  |

输入输出样例 #1

输入：

```
4
yummy or yucky?
eat or stick?
rua or eat?
eat or eat?
```

输出：

```
yummy
stick
rua
or
```

输入输出样例 #2

输入：

```
7
saint or sinner?
tobe or nottobe?
ad or able?
eating or eaten?
or or or?
and or and?
oneplusoneistwo or oneplusoneisthree?
```

输出：

```
sinner
tobe
able
eaten
or
and
oneplusoneistwo
```

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
string a,Or,b;
int main(){
    int q;
    for(cin>>q;q;q--){
        cin>>a>>Or>>b;
        b.pop_back();
        if(a=="eat"){
            if(b=="eat"){
                cout<<Or<<endl;
            }else{
                cout<<b<<endl;
            }
        }else{
            cout<<a<<endl;
        }
    }
    return 0;
}
```
