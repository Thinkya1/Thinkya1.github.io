## 题意

简述：

小蓝正在数轴上挖矿，数轴上一共有  个矿洞，第  个矿洞的坐标为 。小蓝从  出发，每次可以向左或向右移动  的距离，当路过一个矿洞时，就会进行挖矿作业，获得  单位矿石，但一个矿洞不能被多次挖掘。小蓝想知道在

## 代码

### C

```c
#include <stdio.h>

const int N = 2e6 + 10;
int n,m,l[1000],r[1000],ans,cnt;

int max(int a, int b) {
    return (a > b) ? a : b;
}
int main(){
    
    scanf("%d %d",&n,&m);
    for(int i=1,x;i<=n;i++){
        scanf("%d",&x);
        if(x<0){
            l[-x]++;
        }else if(x>0){
            r[x]++;
        }else{
            cnt++;
        }
    }
    for(int i=1;i<=m;i++){
        l[i]+=l[i-1];
        r[i]+=r[i-1];
    }
    for(int i=1,t;i<=m;i++){
        t=l[i];
        if(m-i*2>0){
            t+=r[m-i*2];
        }
        ans=max(ans,t);
        t=r[i];
        if(m-i*2>0){
            t+=l[m-i*2];
        }
        ans=max(ans,t);
    }
    printf("%d\n",ans+cnt);
    return 0;
}
```
