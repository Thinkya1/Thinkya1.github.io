# P2241

## 题目

题目描述：

有一个  方格的棋盘，求其方格包含多少正方形、长方形（不包含正方形）。

输入格式：

一行，两个正整数 （）。

输出格式：

一行，两个正整数，分别表示方格包含多少正方形、长方形（不包含正方形）。

数据范围与说明：

输入输出样例 #1

输入：

```
2 3
```

输出：

```
8 10
```

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
long long n,m,sqr,rec;
int main(){
    cin>>n>>m;
    for(int i=0;i<n;i++){
        for(int j=0;j<m;j++){
            if(i==j)    sqr+=(n-i)*(m-j);
            else    rec+=(n-i)*(m-j);
        }
    }
    cout<<sqr<<" "<<rec<<endl;
    return 0;
}
```
